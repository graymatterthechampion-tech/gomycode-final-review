## What the bootcamp taught me beyond syntax

- **Planning beats rushing.** My best work started with a written scope and data model, not with code.
- **Scope is a skill.** Cutting a project down to what can be delivered well, with a roadmap for the rest, is harder and more valuable than adding features.
- **Debugging is most of the job.** Missing returns, environment errors, CSS conflicts — learning to read errors calmly changed how fast I improve.
- **Honesty about my work matters.** I've learned to describe projects exactly as they are — finished, in progress or private — rather than overstate them.
